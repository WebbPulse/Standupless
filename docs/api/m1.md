# M1 API contract: workspaces and projects

Fixed shape both halves build against. Routes are under `/api`. Every list body is an object with one plural key, never a bare array. Timestamps are ISO 8601 UTC. Ids are ULIDs unless noted. Errors use the platform envelope; a caller outside a workspace sees 404, never 403, for the workspace and anything inside it.

## Workspaces (`workspaces` domain)

| Method and path | Body in | Body out | Who |
|---|---|---|---|
| `GET /workspaces` | none | `{"workspaces": [Workspace]}` (every workspace the caller is a member of, from `memberships` `user_id-workspace_id-index`) | any signed in user |
| `POST /workspaces` | `{"name", "slug"}` | `Workspace`, 201; caller becomes `owner` | any signed in user |
| `GET /workspaces/{workspace_id}` | none | `Workspace` | member |
| `PATCH /workspaces/{workspace_id}` | `{"name"?}` | `Workspace` | owner, admin |
| `DELETE /workspaces/{workspace_id}` | none | 204 | owner |
| `GET /workspaces/{workspace_id}/members` | none | `{"members": [Member]}` | member |
| `PATCH /workspaces/{workspace_id}/members/{user_id}` | `{"role"}` | `Member` | owner, admin; only owner may grant or remove `owner` |
| `DELETE /workspaces/{workspace_id}/members/{user_id}` | none | 204; the last owner cannot be removed | owner, admin, or the user themself |
| `GET /workspaces/{workspace_id}/invites` | none | `{"invites": [Invite]}` | owner, admin |
| `POST /workspaces/{workspace_id}/invites` | `{"email", "role"}` (role never `owner`) | `Invite` plus `token` once, 201 | owner, admin |
| `DELETE /workspaces/{workspace_id}/invites/{invite_id}` | none | 204 | owner, admin |
| `POST /invites/accept` | `{"token"}` | `Member`, 201; idempotent for an existing member | any signed in user |

`Workspace`: `id`, `name`, `slug` (lowercase, `[a-z0-9-]{3,40}`, unique through `slug-index`), `plan` (`"free"`), `created_at`, `role` (the caller's role, only present on responses to a member).
`Member`: `user_id`, `email`, `display_name`, `role`, `joined_at`.
`Invite`: `invite_id`, `email`, `role`, `invited_by`, `expires_at`, `created_at`.

## Projects (`projects` domain)

| Method and path | Body in | Body out | Who |
|---|---|---|---|
| `GET /workspaces/{workspace_id}/projects` | none | `{"projects": [Project]}`; a guest sees only projects they are a member of | member |
| `POST /workspaces/{workspace_id}/projects` | `{"name", "key_prefix", "estimate_scale"?}` | `Project`, 201; creator becomes project `admin`; default statuses seeded | owner, admin, member |
| `GET /workspaces/{workspace_id}/projects/{project_id}` | none | `Project` | project reader |
| `PATCH /workspaces/{workspace_id}/projects/{project_id}` | `{"name"?, "estimate_scale"?, "description"?}` | `Project` | project admin |
| `DELETE /workspaces/{workspace_id}/projects/{project_id}` | none | 204 | workspace owner or admin |
| `GET .../projects/{project_id}/members` | none | `{"members": [ProjectMember]}` | project reader |
| `PUT .../projects/{project_id}/members/{user_id}` | `{"role"}` | `ProjectMember` | project admin |
| `DELETE .../projects/{project_id}/members/{user_id}` | none | 204 | project admin |
| `GET .../projects/{project_id}/statuses` | none | `{"statuses": [Status]}` ordered by `position` | project reader |
| `POST .../projects/{project_id}/statuses` | `{"name", "category", "position"?}` | `Status`, 201 | project admin |
| `PATCH .../projects/{project_id}/statuses/{status_id}` | `{"name"?, "category"?, "position"?}` | `Status` | project admin |
| `DELETE .../projects/{project_id}/statuses/{status_id}` | none | 204; 409 when it is the last status of its category | project admin |
| `GET .../projects/{project_id}/labels` | none | `{"labels": [Label]}` | project reader |
| `POST .../projects/{project_id}/labels` | `{"name", "color"}` | `Label`, 201 | project admin |
| `PATCH .../projects/{project_id}/labels/{label_id}` | `{"name"?, "color"?}` | `Label` | project admin |
| `DELETE .../projects/{project_id}/labels/{label_id}` | none | 204 | project admin |

`Project`: `id`, `workspace_id`, `name`, `key_prefix` (uppercase `[A-Z][A-Z0-9]{1,5}`, unique per workspace through `workspace_key_prefix-index`), `description` (nullable), `estimate_scale` (`"off" | "fibonacci" | "linear" | "tshirt"`, default `"off"`), `next_issue_number` is never exposed, `created_at`, `updated_at`, `role` (the caller's project role: `admin` or `member`, or the workspace role's implied `admin` for owner and admin, `member` for member).
`ProjectMember`: `user_id`, `email`, `display_name`, `role` (`admin` or `member`), `added_at`.
`Status`: `id`, `name`, `category` (`backlog | unstarted | started | completed | cancelled`), `position` (integer, ascending). Default seed on create: Backlog (backlog, 0), Todo (unstarted, 1), In Progress (started, 2), Done (completed, 3), Cancelled (cancelled, 4).
`Label`: `id`, `name`, `color` (`#rrggbb`).

"Project reader" is any workspace owner, admin or member, or a guest holding a project membership. "Project admin" is a workspace owner or admin, or a project member with role `admin`.
